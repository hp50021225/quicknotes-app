# QuickNotes App

QuickNotes is a lightweight, responsive note-taking web application designed to help users capture, organize, and search their thoughts efficiently with local storage persistence.

## Features
- Add notes with categories (Personal, Work, Study).
- Real-time form validation for empty entries and character limits (max 200).
- Instant search filtering.
- Persistent local storage across browser reloads.
- Fully responsive design for mobile and desktop screens.

## How to Run Locally
1. Clone or download this repository.
2. Open the folder in VS Code.
3. Open `index.html` via Live Server or a browser.

## What I Learned
1. Implementing robust client-side form validation and error handling using JavaScript.
2. Managing state with arrays of objects and saving/loading state via `localStorage`.
3. Ensuring secure dynamic DOM rendering with `createElement` and `textContent`.
